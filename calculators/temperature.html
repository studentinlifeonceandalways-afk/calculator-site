Temperature Converter

Use this temperature converter to convert between Celsius, Fahrenheit, and Kelvin. Enter a value and select the from and to units. Conversions use exact scientific definitions: water freezes at 0 °C / 32 °F / 273.15 K and boils at 100 °C / 212 °F / 373.15 K at standard pressure. Absolute zero is 0 K / −273.15 °C / −459.67 °F.

Assumptions and limitations

  • Values below absolute zero are not physically meaningful (below 0 K, −273.15 °C, −459.67 °F)
  • No unit rounding beyond the displayed precision
  • For scientific work requiring high precision, use standard reference tables

How the calculation works

°F = (°C × 9/5) + 32

°C = (°F − 32) × 5/9

K = °C + 273.15

°C = K − 273.15

Frequently asked questions

Why does Kelvin have no degree symbol?

Kelvin is an absolute temperature scale, so "K" is a unit name rather than a degree. Conventionally written as 273.15 K, not 273.15 °K.

What is room temperature in each unit?

About 20–22 °C, 68–72 °F, or 293–295 K.

Can I convert negative temperatures?

Yes, but not below absolute zero (−273.15 °C, −459.67 °F, 0 K). The calculator will flag clearly invalid values below those thresholds.
